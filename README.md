# Бондаренко — всегда в движении

Личный сайт Василия: спортивный журнал с настоящими фотографиями, историей Астана → Алматы, зимним разворотом, баскетболом, залом и Dota 2.

**Открыть сайт: https://vladimirsnow.github.io/kupitman/**

## Запуск

Нужен Node.js. Устанавливать зависимости не требуется.

```sh
npm run dev
```

Откройте http://127.0.0.1:4173 . Или запустите `python3 -m http.server 4173` из папки проекта. Для 3D нужен запуск через HTTP, а не открытие файла двойным кликом.

## Публикация

- **GitHub Pages:** Settings → Pages → Deploy from a branch → `main` → `/ (root)`. В корне есть `.nojekyll`. Обновления публикуются после push в main.
- **Vercel:** импортировать репозиторий. Конфигурация уже в `vercel.json`: команда `npm run build`, результат `dist`, без фреймворка. Сборка использует только встроенные модули Node.js.
- Другой статический хостинг: выполнить `npm run build` и загрузить содержимое `dist/`.

Все пути относительные: сайт работает и в подпапке GitHub Pages. Внешних CDN, запросов к API, аккаунтов и платных сервисов для работы нет.

## Что внутри

- `index.html` — контент и разметка.
- `style.css` — адаптивный дизайн от 320 px.
- `app.js` — галерея, клавиатура, свайпы и GSAP ScrollTrigger.
- `ball.js` — Three.js мяч с освещением, геометрическими швами и кнопкой вращения. При отсутствии WebGL остаётся CSS-мяч. При скрытой вкладке или вне экрана 3D приостанавливается.
- `assets/` — WebP, локальные шрифты, библиотеки и лицензии.
- Пять JPG в корне — неизменённые исходники; галерея показывает их в полном разрешении.
- `SOURCES.md` — полный список скачанного и источников.
- `VERIFICATION.md` — проверки и результаты визуального обзора.

Увеличенные заголовки, смена светлых и тёмных разворотов, наклонные фото и зимний параллакс создают характер. Режим `prefers-reduced-motion` отключает автодвижение. Нативный dialog удерживает фокус; Escape закрывает фото, ←/→ листают, фокус возвращается к исходной кнопке. На телефоне доступны свайпы и обычные кнопки.

Возраст и дата рождения указаны по предоставленному описанию. Новые биографические достижения, игровые ранги и контакты не выдуманы. Фотографий из интернета и ИИ-изображений нет.

## Правки

Биография находится непосредственно в HTML. Список фото и подписей — в начале `app.js`. Для замены оптимизированных изображений используйте те же имена в `assets/` и обновите оригиналы/список галереи. Палитра — CSS-переменные в начале `style.css`.

```sh
npm run check
npm run build
```

Локальные дизайнерские материалы и скриншоты хранятся в `.oil-ui/portrait/`, в Git они не отправляются.
